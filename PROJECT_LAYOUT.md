# Project Layout

- `pull-push/`: main PICA training, evaluation, rollout, and optional pre-approach demo code.
- `main_table_worktrees/`: main-table baselines, unified evaluation, and summary scripts.
- `GAPartNet/`: GAPartNet/manipulation code used for main-table row 02.

Large datasets, simulator assets, checkpoints, outputs, videos, and logs are ignored. Placeholder `.gitkeep` files preserve the expected local directory layout.
